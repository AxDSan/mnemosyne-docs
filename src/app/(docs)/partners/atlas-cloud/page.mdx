<Callout type="info" title="Sponsored — Compute Partner">

[Atlas Cloud](https://www.atlascloud.ai/?utm_source=github&utm_medium=link&utm_campaign=mnemosyne) is a full-modal AI inference platform: a single API for 300+ curated models across LLM, image generation, and video generation. You connect once instead of maintaining a separate vendor integration per modality.

Relevant to Mnemosyne: the chat endpoint is **OpenAI-compatible**, so it drops into the existing remote-LLM path with no adapter and no code change.

## Using Atlas Cloud with Mnemosyne

Mnemosyne calls an LLM for two things: **sleep consolidation** (summarizing working memories into episodic ones) and **fact extraction** (`remember(extract=True)`). Both go through the OpenAI-compatible remote path.

```bash
export MNEMOSYNE_LLM_ENABLED=true
export MNEMOSYNE_LLM_BASE_URL=https://api.atlascloud.ai/v1
export MNEMOSYNE_LLM_API_KEY=your-atlas-cloud-key
export MNEMOSYNE_LLM_MODEL=deepseek-v3
```

Verify the wiring with a consolidation run:

```bash
mnemosyne sleep --dry-run
```

Same variables work for the Hermes plugin — it reads the Mnemosyne environment directly.

### Fallback chain

Set Atlas Cloud as the fallback instead, and Mnemosyne only reaches for it when the primary endpoint fails:

```bash
export MNEMOSYNE_LLM_FALLBACK_BASE_URL=https://api.atlascloud.ai/v1
export MNEMOSYNE_LLM_FALLBACK_API_KEY=your-atlas-cloud-key
export MNEMOSYNE_LLM_FALLBACK_MODELS=deepseek-v3
```

Full precedence order is documented in [LLM Backends](/architecture/llm-backends).

<Callout type="warning" title="Memory content leaves the machine">
Any remote LLM endpoint — Atlas Cloud included — receives the memory text being consolidated or extracted. If that is not acceptable for your data, leave `MNEMOSYNE_LLM_BASE_URL` unset and Mnemosyne falls back to the local GGUF model, then to AAAK extractive compression. Both run fully offline. See [Data Privacy](/security/data-privacy).
</Callout>

### Embeddings stay local

This configures the LLM path only. Embeddings still run locally through fastembed (`BAAI/bge-small-en-v1.5`, 384 dimensions) unless you explicitly enable [cloud embeddings](/getting-started/configuration).
